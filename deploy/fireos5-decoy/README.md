# Not an overdub release

This tarball exists so that a Dot on v0.3.0, the last Fire OS 5 release, is
offered this release and told how to move to it. It holds no overdub binary.

Download `overdub-<tag>-fireos6.tar.gz` from the same release instead. Connect
the Dot by USB and run its `deploy/install.py`: it moves the Dot to Fire OS 6
with firebreak, keeps its setup and keys, and then installs.
