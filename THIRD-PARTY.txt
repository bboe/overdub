Third-party notices for overdub
===============================

overdub itself is BSD 2-Clause; see LICENSE.txt. This file is for the code it
does not own.

Source distribution needs nothing beyond this file. A COMPILED overdub is
different: the packages below are linked into the binary, and clause 2 of each
BSD licence among them asks that its copyright notice, conditions and disclaimer
travel with it. So ship this file alongside any binary you publish. The release
tarball carries it, beside LICENSE.txt.

go.mod and go.sum are the authority on versions. Each licence below is copied
verbatim, from the module's own LICENSE or, for what the NDK links in, from the
NDK's own NOTICE.

LLVM compiler-rt builtins, supplied by the Android NDK, need no notice, and
that is the exception rather than an omission.

The same link embeds __aeabi_uidivmod, __aeabi_idiv0 and __aeabi_ldiv0 from
libclang_rt.builtins-arm-android.a. Go's runtime defines none of those three.
compiler-rt is Apache-2.0 WITH LLVM-exception, and the exception says that
portions embedded into object form as a result of compiling may be
redistributed without complying with sections 4(a), 4(b) and 4(d) -- which are
the copy-of-the-licence and NOTICE requirements. So they are named here and
their licence is not reproduced.

github.com/mewkiz/flac -- the FLAC decoder in internal/sendspin/flac.go
Unlicense: dedicated to the public domain, so it needs no notice.

It requires 3 modules indirectly. github.com/mewkiz/pkg and github.com/mewpkg/term
are Unlicense too. github.com/icza/bitio is Apache-2.0. The binary's build info
lists all 3, and none contributes a symbol: only the encoder calls them, and the
linker drops it.
