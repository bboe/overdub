# Rooting

Rooting moved to [firebreak](https://github.com/bboe/firebreak), which
replaces `dot_firmware.py`.
[firebreak's README](https://github.com/bboe/firebreak#readme) says how to run
it, and its
[docs/rooting.md](https://github.com/bboe/firebreak/blob/main/docs/rooting.md)
says why each step is there. The targets are now `amonet-biscuit-v1.1.0-bboe`
(was `v1-bboe`), `amonet-biscuit-v1.1.0` (was `v1`) and
`amonet-biscuit-v2.0.0` (was `v2`). `stock BUILD` is the same.
